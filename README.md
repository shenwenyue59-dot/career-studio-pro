# Career Studio Pro

一个本地运行的简历、JD 研究和作品集 PPT 策划工具。

## 使用方式

1. 直接打开 `index.html`：可以使用规则模式。
2. 双击 `start-career-studio.bat` 或运行 `node server.js`：可以启用链接读取和 AI 接口。
3. 在工作区 `.env.local` 写入 `OPENAI_API_KEY=...` 后，AI 润色、JD 分析和作品集逐页方案会调用 OpenAI API。
4. 打开 `http://localhost:4173` 使用服务版。

## 关于 JD 获取

猎聘、Boss 直聘、LinkedIn 等网站经常需要登录、验证码或限制自动访问。工具支持公开链接的尽力读取；遇到限制时，推荐复制 JD 原文粘贴到工具中，这样更稳定，也更符合账号安全。

## 关于方向匹配

先用自然语言写清楚你想做的方向、偏好的工作内容、不想做的内容、当前背景和目标级别。工具会生成 Boss 直聘、猎聘、LinkedIn 的搜索词组合，并给出核心命中词、辅助命中词和排除词。

验证方式：用推荐词在平台搜索，复制 2-5 条搜索结果里的 JD 到“验证 JD”。如果核心词命中率高、跑偏词少，就可以继续收集 JD；如果跑偏，工具会提示该收窄岗位名、增加行业词，还是加入排除条件。
